# 🎨 Cerebras Cafe Compute

A web-based attendee poster generator created for the **Cerebras Cafe Compute** event.

The application allows attendees to enter their name, designation, and upload a photo to generate a personalized **"I'm Attending"** event poster that can be downloaded and shared on social media.

## ✨ Features

- 🎟️ Personalized attendee poster generation
- 📝 Attendee name and designation input
- 📸 Photo upload and circular profile image placement
- 🎨 Cerebras Cafe Compute themed design
- 📱 Responsive and mobile-friendly interface
- ⚡ Fast client-side poster generation
- 💾 Download personalized attendee poster
- 🔗 Share-ready social media caption
- 💻 Clean and modern user interface

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- HTML5
- CSS3
- HTML Canvas API
- Vercel – Deployment
- GitHub – Version Control

🎯 How It Works
Open the Cerebras Cafe Compute attendee poster generator.
Enter your name.
Enter your designation.
Upload your photo.
Generate your personalized "I'm Attending" poster.
Preview the generated poster.
Download the poster.
Share it on social media.
🎨 Poster Generation

The application uses the HTML Canvas API to dynamically generate the attendee poster.

The uploaded photo is automatically fitted inside the circular profile area without stretching the image. The attendee's name and designation are then added below the profile section.

📱 Responsive Design

The application is designed to work across:

💻 Desktop
📱 Mobile
📲 Tablet

The interface automatically adapts to different screen sizes for a smooth attendee experience.

🎯 Purpose

This project was created for the Cerebras Cafe Compute initiative to provide attendees with a simple and engaging way to create and share personalized "I'm Attending" posters.

The goal is to make attendee participation more interactive while providing a professional, event-branded social media asset.
